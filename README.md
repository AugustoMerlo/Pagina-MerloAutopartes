# Merlo Autopartes

Sitio web estático y adaptable a móviles, desarrollado con HTML, CSS y JavaScript nativo.

## Desarrollo local

No requiere instalar dependencias ni ejecutar una compilación. Para previsualizarlo desde la carpeta del proyecto, iniciá un servidor local:

```powershell
py -m http.server 8000
```

Abrí `http://localhost:8000` en el navegador.

## Archivos principales

- `index.html`: contenido y estructura del sitio.
- `styles.css`: estilos y diseño adaptable.
